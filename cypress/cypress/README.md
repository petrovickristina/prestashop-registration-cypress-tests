# QA Automation Task – Cypress

## 📌 Project Description
This project contains automated test cases for the user registration functionality on a PrestaShop demo website.

The goal is to validate both positive and negative scenarios using Cypress.

---

## 🚀 Tech Stack
- Cypress
- JavaScript
- Node.js

---

## 🌐 Tested Application
https://hellish-machine.demo.prestashop.com/

---

## 🧪 Test Scenarios

### ✅ Positive
- Successful user registration

### ❌ Negative
- Empty form submission
- Invalid email format
- Short password
- Missing GDPR consent

### ⚠️ Edge Cases
- Already registered email
- Invalid characters in name fields
